# 视频评测工作台

[打开交互工作台 ↗](https://xiesy0229.github.io/multimodal-agent-evaluation-handbook/video-workbench/){ .md-button .md-button--primary }

用八个步骤理解评测流程，再导入自己的 CSV，并排比较模型 A / B 的视频、记录四档判断和具体评语。

- 浅粉、淡紫、奶白配色，适配手机和桌面。
- 支持 Prompt 搜索、标注筛选、分页、媒体高度及循环播放。
- 支持双视频播放、分别试听、标注导出与重新导入。
- 文件在浏览器内处理；远程媒体仍会访问原视频地址。标注不在服务器保存，请及时导出。

演示题集不含真实模型视频或评分结果。工作台只记录单人综合比较；正式多人评测请参阅 [完整方法](pairwise-video-evaluation.md) 和 [评测 Skill](evaluation-skill.md)。
