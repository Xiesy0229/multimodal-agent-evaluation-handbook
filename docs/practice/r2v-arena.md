# R2V Arena｜参考图视频生成模型能力评测

这是一个由 **R2V Arena 交互式评测平台**与 **R2V Eval Set Builder Skill** 组成的个人项目，聚焦“如何把参考图生成视频（R2V）的能力评测做得更结构化、可复核”。

## 项目组成

### 1. R2V Arena：评测体验与维度验证

当前平台提供 15 道双视频比较题，支持逐题评分、评测维度适用性反馈、结果汇总和 CSV 导出。它主要用于验证评测维度和收集评审反馈，不应被理解为已经完成大规模模型横评或自动化裁判。

[打开 15 题评测页面](r2v_Arena_15题_维度验证_含逐题反馈版.html){ .md-button .md-button--primary }

### 2. R2V Eval Set Builder：题集构建与预检 Skill

Skill 面向“文本 + 静态参考图”的 R2V 题集准备，协助整理题目和图片素材、记录标签/考察依据/来源、检查任务在目标时长内是否可执行，并按可配置规则校验语言、镜头类型、风格和参考图数量等覆盖情况。提供本地 Python 校验器，帮助检查配置、数据结构、素材引用和完整性；建议先做小样，再扩充题集。

[查看 Skill 文件与使用说明](https://github.com/Xiesy0229/multimodal-agent-evaluation-handbook/tree/main/skills/r2v-eval-set-builder)

## 端到端工作方式

```text
定义评测目标与能力维度
        ↓
规划覆盖面与题集配额
        ↓
准备文本提示词 + 有来源记录的参考图
        ↓
Skill 预检结构、覆盖和时长可执行性
        ↓
人工复核题目与素材 → 小样试跑 → 修订
        ↓
在 Arena 中比较视频、逐题评分并反馈维度
        ↓
导出结果，归纳问题与下一轮题集改进方向
```

## 当前范围与说明

- 当前 Skill 负责题集构建、素材/元数据整理与结构性预检；**不会默认调用视频模型生成结果，也不会自动判定模型优劣**。
- Arena 当前版本用于双视频逐题比较与维度验证；结果仍需结合评审标准和人工复核解释。
- 参考图的语义匹配、权利与许可、题目是否真正覆盖目标能力，以及生成视频的质量判断，需要人工检查。
- Skill 中的默认数量与配额可按项目目标调整，不代表行业标准。
