白模参考输入与用户使用链路

用户会怎样准备参考素材，再交给参考图生成视频（R2V）模型？这份报告把白模从“怎么做出来”到“最后输入什么”串成一条清楚的链路。

先理解“白模”：低细节的人物或场景占位模型。它不追求精致外观，主要用来说明人物站位、动作、空间关系和镜头运动。

产品启发

评测和训练数据应尽量贴近用户真正能准备的参考素材。但本报告没有跨平台使用量统计，因此“多数用户会用哪种白模”仍是待验证假设，不能当成已证实的市场结论。

本轮样例可证明这些形态在所调研平台中存在，但尚无跨平台上传占比统计；“大部分用户会用这类参考”是待验证的产品假设，不是本报告已证实的市场结论。

这份调研说明了什么？

01

白模不只有一种

既有静态构图图、多机位图片，也有记录动作和运镜的预演视频。

02

模型收到的通常是媒体文件

案例中的模型输入是图片或 MP4 + 人物/场景素材 + 文字；可编辑的 3D 工程文件往往需要先渲染成图片或视频。

03

参考素材各有分工

白模负责讲清位置、动作或镜头；人物图负责外观；场景图负责环境。提示词补充文字要求。

04

调研事实和产品假设要分开

报告记录了可查看的平台样例与官方资料；它不是用户占比调查，也不是模型质量横评。

可以把白模理解成“拍摄前的走位草图”：先把谁在哪里、怎么动、镜头往哪走表达出来，再交给生成模型参考。

补充类型：白模人物＋几何体块参考

用户导入目的：先用人偶和简单体块摆出人物与环境的关系，说明人在哪里、物体有多大、谁挡住谁，以及动作需要多少空间。

用户怎么做：用户放入人偶，再用长方体、平面等搭桌面、墙体或障碍物的占位；调整体块大小、人物站坐姿态与机位，拍成图片，或把人物/相机运动录成视频。需要替换外观时，再提供目标人物、场景图片与文字说明。

实际输入模型的参考

本次已核对的动态实例就是案例3A：人偶＋灰色墙体/遮挡物的MP4（1920×878，15秒）＋场景外观图＋文字。围桌静态图用于展示组合形态，是官方示例配图，未核实其提交到生成节点的输入文件。

用户希望确定什么最直白的理解
位置关系人在体块前后、左右或两侧；谁围着谁、相隔多远。
大小比例桌面到人腰部还是胸口、墙体相对人有多高；表达相对尺度。
遮挡层次墙或桌挡住腿部/半身、人物从遮挡后露出；说明哪些部分应可见。
站坐与接触位置人站着或坐着，手脚靠近哪个表面；表达姿态和大致对齐位置。
活动空间与路线从体块旁经过、绕开障碍、穿过通道；说明动作可用的空间。
构图与人景占比从选定机位看，人和环境各占多少画面，前景体块遮住多少主体。
本例结论

白模人物提供人体尺度与姿态，几何体块提供环境体量和空间边界；两者一起参考的是“人和环境的关系”，不只是人物位置。体块可代表桌子、墙体或障碍物，不一定要在成片里保留成方块。

建议补充的训练数据类型

建议加入“白模人物＋几何体块”的图片/视频参考，覆盖人物与体块的远近、相对大小、高低、前后遮挡，以及围坐、靠近、绕行等关系；搭配目标人物/场景素材与明确文字，区分“保留空间布局、替换体块外观”和“保留几何体本身”两种意图。

上述用途是产品归纳，不代表每个样例都展示了全部用途。画面提供的是可见的相对关系，不能直接当作米制距离、碰撞检测或接触物理的验证。体块代表什么、是否需要替换外观，应由文字或场景参考进一步说明。

角色模型结论

角色白模不止一种标准成人：性别外观、体型、年龄段、卡通比例和群体排列都可能不同。人物主要表达姿态与人物关系，几何体主要补充场景、道具与空间；两张新增菜单证明选项存在，不等于这些模型均已完成独立导出。

建议补充的训练数据类型

建议加入男女素体、宽厚/健壮/纤细、少年/儿童、二头身/卡通、群众阵列等不同轮廓与比例；极简圆柱体单列位置/尺度参考，几何体单列场景/道具，外部导入资产另保留其材质差异。

案例1：基础白模参考

用户导入目的：先把两个人站在哪里、面向哪里和画面构图说明白，再让AI生成指定人物。

本例结论

案例2：白模多机位参考

用户导入目的：同一场戏使用多个机位时，让人物站位、相对关系和角色外观保持可对照。

  1. 用户先做什么：用户在同一个拳台场景中摆两个人偶，切换机位分别拍正打和反打，再准备角色A/B的设定图。
  2. 得到的参考：两张不同机位的白模图片。它们表达同一场景的多个观察方向，不是两个独立3D工程。
实际输入模型的参考

2张白模机位图 + 1张拳台背景图 + 2张角色图 + 文字描述，共5张直接上游图片。

本例结论

本例同时给正反打白模图、拳台图与角色图，属于多机位参考，不只是单张首帧。

建议补充的训练数据类型

建议加入“同场景多机位白模图组＋角色/场景参考”的组合，包含正反打、不同景别、同色双人和遮挡变化；多张机位图应关联到同一组角色，而非新增人物。

既有成片显示拳台内双人对话及不同人物角度。1280×720，约8.06秒。
