# 人员质检与统计方法

以下是这套方法的默认计分与诊断规则，不是适用于全部数据集的客观质量标准。项目开始前记录人员组、维度集合、样本量、实质影响阈值与强败局阈值。GT 仍需人工确认。

## 数据与四档

一行可为一名人员对一道题的完整评分；长表则以人员 × 题号 × 维度为唯一单元，保留源行索引。G 为模型 B 明显更好，B 为模型 A 明显更好，As good 为双方都较好，As bad 为双方都有问题。综合维度与分维度独立统计。

## GT 候选与计分

实际维度数 K，每维默认强 G、强 B、Similar 各一题，共 3K 道互不重复原题；G/B 以唯一众数且高一致为优先，Similar 以 As good 或 As bad 的唯一众数为优先。整套覆盖两种 Similar，披露争议与每人覆盖数。

人工标准答案 y 与个人答案 a 的计分：

| 条件 | 得分 |
| --- | --- |
| y = a | 1.0 |
| 不同标签但同一计分极性 | 0.7 |
| 计分极性不同 | 0.0 |

这里的“计分极性”是源方法的部分得分约定：G / As good 为一组，B / As bad 为另一组。它不改变 As good / As bad 的语义，不代表 Similar 档在事实上证明某个模型获胜。报告注明此约定；项目若采用其他 GT 距离函数，需另行记录而不能混用。

个人 GT 得分取实际覆盖有效单项的均值，另报完全一致、同极性、跨极性与有效 GT 数，避免用命中次数比较覆盖量不同的人员。

## 人员指标

### 留一同题共识

对个人每个题号 × 维度，排除本人后统计同组众数；答案命中任一并列众数记 1，否则记 0，取有效单元均值。没有同题同维参照时记缺失并披露分母。

### 跨维独立性与标签多样性

全维同分率 = 同一道题全部一级维度相同的题数 / 有效题数；跨维独立性 = 1 - 全维同分率。

标签多样性 = -Σ(p_l × ln p_l) / ln(4)，零占比项不参与求和。低多样性只能作为风险信号，不能单独证明错误。

### 维内跨题变化性

对每维 d 比较本人标签熵 H_person,d 和排除本人的同组标签熵 H_peer,d。若 H_peer,d < 0.25，variation_d = 1；否则 variation_d = min(1, H_person,d / H_peer,d)，再对有效维度平均。

本人该维最高频标签占比 ≥95%，同组同标签占比 <90%，记为一个异常固定维度。比较仅使用可比题组；高度单边的数据不应自动误判为机械打分。

### 净偏好与方向

只用综合评价计算 net = (n_G - n_B) / n_all。个人与同组其余人绝对差为 d：

- d ≤0.25：偏好接近度 = 1。
- d >0.25：偏好接近度 = max(0, 1 - (d - 0.25) / 0.55)。

两者 net 同号或任一为零记方向一致。优先同盒、同题段、同一批可比人员，不跨不重叠题组硬比较。

## 独立检查评分强度偏差

strength(G)=strength(B)=1，strength(As good)=strength(As bad)=0。

对本人实际评过的同题同维单元，排除本人后建立同组参照，输出：

- 个人强档率：本人 G/B 占比。
- 同题同维同组强档率：每个可比单元其余人员的强档比例，再在单元之间平均。
- 强档差：个人强档率减同组强档率。
- 强度一致率：本人强弱档是否命中同组强弱档众数，并列命中任一记一致。
- 同方向过度强调率：方向可比且一致的单元中，本人选 G/B、同组强度唯一众数为弱档的比例。

“方向”比较遵循本项目明确记录的计分极性口径；方向或参照强度不能唯一确定时，披露并列情况并排除该过度强调率的分母，不暗中选择有利方向。全部指标另按维度输出并附分母。

源方法默认风险信号：

| 信号 | 最小可比量 |
| --- | --- |
| 全量强档差 ≥+0.20 | 30 个单元 |
| 至少两维强档差 ≥+0.25 | 每维 10 个单元 |
| 同方向过度强调率 ≥60% | 20 个同方向可比单元 |

过度保守可以对称诊断负向差值。这些阈值是方法默认值，小样本需解释，不机械用于剔除。净偏好方向正确不能豁免强度检查。

## 综合分与风险

源方法综合分为：

```text
Total = 35×GT + 20×留一同题共识
      + 10×跨维独立性 + 10×标签多样性
      + 5×维内变化性 + 15×偏好接近度 + 5×方向一致
```

子指标先保留未舍入值，最终展示一位小数。子指标缺失时披露，不静默填零生成可比排名。强度偏差作为独立门禁，不改写上述权重。

以下任一项作为人员风险：

- 异常固定维度 ≥3 且维内变化性 <0.30。
- 综合维度单一标签占比 ≥95% 且个人与同组净偏好差 >0.35。
- 命中上述强度偏差信号。

## 单人剔除与实质影响

先用全量有效人员计算，再单独删除每名风险人员的底层记录重算；分别比较全量和所属组的综合 GSB 绝对变化与所有维度的最大绝对变化。

必须剔除 = 人员风险 AND 项目事先约定的实质影响条件。源材料未给出统一实质影响阈值，此公开版不补造固定数值。若阈值未约定，交付诊断和敏感性结果，等待确认。

多人组合剔除后重新整体计算，各单人变化不能相加。零分母时报告分布变化及无穷/不可稳定计算，不人为加极小数。

## 每题等权

对每个维度分别计算第 i 题剩余有效票数 n_i，w_ij=1/n_i。四档加权数量之和等于该维度有有效票的题数，百分比之和为 100%。

Similar = As good + As bad；GSB = (G+0.5×Similar)/(B+0.5×Similar)。票数一致时与行加权等价；票数不一致时正文使用题目等权，行加权仅作敏感性对照。无有效票题目单列，不参与上述分母。

## 完整性检查

题号/人员/维度唯一，非法标签与缺失显式处理；GT 原题不重复且覆盖可解释；模型方向一致，Prompt/URL 同题对齐；过滤名单与底层记录一致；每题权重闭合，报告数字可追溯。公开展示只使用已脱敏、获准公开的数据。
