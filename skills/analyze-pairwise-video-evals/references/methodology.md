# GSB 人员质检 methodology

# 方法与公式

## 数据标准化

建议将一行定义为“一名标注员对一道题的完整评分”，至少保留：题号、标注员、组别、Prompt、模型 A URL、模型 B URL、实际评价维度答案、影响因素、白黑盒或来源、时长。原表若是一维一行，先建立等价的长表，但输出时保留原题和原行索引。

仅接受四个标准标签：

- `G (Good)`：模型 B 明显更好
- `As good`：双方都较好
- `As bad`：双方都有明显问题
- `B (Bad)`：模型 A 明显更好

如果项目方向相反，先把方向统一为上述内部口径，并在所有输出显式说明转换；不得一半使用原方向、一半使用内部方向。

## GT 候选选择

先按“题号 × 目标维度”统计四档票数、一致率、胜负净票和参与人员。设实际需要质检的评价维度数为 `K`，默认每个维度选三题，共 `3K` 题：

1. 强 G：G 为唯一众数，优先全票或近全票。
2. 强 B：B 为唯一众数，优先全票或近全票。
3. Similar：As good 或 As bad 为唯一众数，优先高一致题。

整套候选应同时包含 As good 与 As bad。若某维没有足够的强共识样本，可选择该维最强的可用样本，但在“候选类型/备注”中如实写“本维最强”或“争议题”，不得伪称全票。

同一原题不得在不同目标维度重复入选。候选 GT 只判目标维度，避免把一题扩成多个 GT 判断而破坏覆盖设计。

当人员分属互斥题组时，先建立 `题号 -> 标注员集合`，再让选中题在各集合间尽量均衡。输出每人 GT 覆盖数；覆盖明显不足时重新选题。

## GT 单项计分

设标准答案为 `y`，个人答案为 `a`：

```text
s(y,a) = 1.0  当 y = a
         0.7  当 y ≠ a 且 polarity(y) = polarity(a)
         0.0  当 polarity(y) ≠ polarity(a)

polarity(G) = polarity(As good) = 模型 B 极性
polarity(B) = polarity(As bad)  = 模型 A 极性
```

个人 GT 得分率为其实际覆盖的有效 GT 单项均值。另报完全一致数、同极性数、跨极性数和有效 GT 数。不同组覆盖量不同时，不直接比较命中次数。

## 正式结果的题目等权

完成人员过滤后，设题目 `i` 剩余有效票数为 `n_i`，该题每条投票权重为：

`w_ij = 1 / n_i`

因此每题总权重恒为 1。四档质量、比例和 GSB 均用这些权重计算：

`Similar = As good + As bad`

`GSB = (G + 0.5 × Similar) / (B + 0.5 × Similar)`

若每题剩余票数完全相同，题目等权与直接按行汇总等价；若剔除集中在某个人员组或题段，两者不再等价，正式结果必须使用题目等权。直接按剩余行汇总的结果只能作为敏感性对照。

## 其余人员指标

### 留一同题共识

对个人的每个“题号 × 维度”，排除本人后统计同组答案众数。若存在并列众数，个人答案命中任一并列众数均计 1，否则计 0。对所有有效单元取平均。

### 题内跨维同分与独立性

若同一道题的全部一级维度答案完全相同，该题记为 1，否则为 0：

`全维度同分率 = 同分题数 / 本人有效题数`

`题内跨维独立性 = 1 - 全维度同分率`

维度数不是 5 时，按该文件实际一级维度集合计算，并在报告注明。

### 标签多样性

令四档占比分别为 `p_i`：

`多样性 = -Σ(p_i × ln p_i) / ln(4)`

其中 `p_i = 0` 的项不参与求和。该值用于发现长期只使用一两档的机械模式，不能单独作为质量结论。

### 维内跨题变化性

题内跨维独立性不能发现“按维度固定打分”，因此还要逐维度检查一名人在所有题上的答案变化。对每个维度 `d` 计算个人归一化标签熵 `H_person,d`，以及排除本人后的同组归一化标签熵 `H_peer,d`：

```text
若 H_peer,d < 0.25：variation_d = 1
否则：variation_d = min(1, H_person,d / H_peer,d)

维内跨题变化性 = 所有评分维度 variation_d 的平均值
```

对每个维度还要记录个人的单一最高频标签占比。若该占比 `≥95%`，且留一同组对同一标签的占比 `<90%`，该维度记为一个“异常固定维度”。同组条件用来避免在整批数据本来就高度单边时误伤正常标注员。

### 偏好接近度与方向

仅用“综合评价”计算个人和同组其余人的净偏好：

`net = (n_G - n_B) / n_all`

设二者绝对差为 `d`，偏好接近度为：

```text
1                              d ≤ 0.25
max(0, 1 - (d - 0.25) / 0.55)  d > 0.25
```

个人 net 与同组其余人 net 同号时方向一致；任一为 0 也记一致。这里的“同组”优先指同盒、同题段或同一批标注员，不要跨不重叠题组比较。

### 评分强度偏差：方向正确也要检查

`G/B` 表示明显胜负，`As good/As bad` 表示两者接近。因此人员质检必须把“胜负方向”和“差异强度”分开。某人即使经常选对方向，若系统性地把小胜打成明显胜，仍是需要识别的标度风险。

先定义强度：

```text
strength(G) = strength(B) = 1
strength(As good) = strength(As bad) = 0
```

对每名人的每个“题号 × 评价维度”，使用排除本人后、评过同题同维的同组人员作为参照，计算：

- `个人强档率`：本人选择 `G/B` 的比例。
- `同题同维同组强档率`：对本人实际评过的每个单元，先计算其余同组人员的强档比例，再在所有单元上取平均。
- `强档差` = `个人强档率 - 同题同维同组强档率`。正值过大表示过度极端，负值过大表示过度保守。
- `强度一致率`：本人强/弱档与排除本人后的同组强/弱档众数一致的比例；众数并列时命中任一并列值均算一致。
- `同方向过度强调率`：在本人与同组其余人方向一致的可比单元中，本人选 `G/B`、但同组强度众数为 `As good/As bad` 的比例。

除全量结果外，必须分评价维度计算强档率和强档差，避免一个人只在某一维度偏极端却被总体平均掩盖。

下列是默认风险信号，项目样本很小时应同时报告分母，不机械套用：

- 全量强档差 `≥ +0.20`，且至少有 30 个可比单元；
- 至少两个评价维度的强档差 `≥ +0.25`，且每维至少有 10 个可比单元；
- 同方向过度强调率 `≥60%`，且至少有 20 个同方向可比单元。

对过度保守可对称检查负向差值。这些信号必须进入人员报告，且不得因为胜负方向一致而忽略。

为保留历史项目的分数可比性，强度偏差暂不改写下方的综合分权重，而是作为独立风险门禁。“必须剔除”仍要同时满足人员风险与逐人剔除后的实质影响；若强度偏差明显但对总体方向影响小，至少列为“高风险观察”并进行档位校准。

### 综合分

```text
Total = 35×GT
      + 20×留一同题共识
      + 10×题内跨维独立性
      + 10×标签多样性
      +  5×维内跨题变化性
      + 15×同组偏好接近度
      +  5×方向一致
```

所有子指标先保持未舍入小数，综合分计算完成后再展示一位小数。

### 机械性与极端偏好风险

以下任一项可作为人员风险，仍需与后文的实质影响联合判定，不得单独直接剔除：

- 异常固定维度 `≥3`，且维内跨题变化性 `<0.30`；
- 综合维度的单一标签占比 `≥95%`，且 `|net_person - net_peer| > 0.35`；
- 命中上述“评分强度偏差”的任一默认风险信号。

第一条发现按维度套模板，第二条发现方向与强度都远离同组的极端偏好。其中“单一标签占比”指综合维度四档中的最高频占比，不是单指 G。

## 剔除敏感性

对每名风险人员分别执行：

1. 用全量有效人员算每维 GSB。
2. 只删除该人员的底层行，重算全量每维 GSB。
3. 在该人员所属组内重复前两步。
4. 记录综合维度绝对变化和所有维度绝对变化最大值。

风险规则和实质影响阈值必须取逻辑“且”才能得到“必须剔除”。多人组合剔除后还要再整体重算，不能把各单人变化简单相加。

若某一 GSB 分母为 0，保留 G/B/Similar 率并将 GSB 标为不可稳定计算或无穷，不用任意极小数掩盖问题。

## 文件完整性断言

程序至少应断言：

- 候选数等于实际评价维度数 ×3，每维 3 题且题号不重复；
- GT 阶段的每个“题号 × 维度”唯一且无空值；
- 原始总行数等于按人员、按题号或按组重算的行数；
- 每个维度 `G + As good + As bad + B = 有效记录数`；
- 每人 GT 覆盖数符合所在题组候选数；
- 每人的题内跨维同分率、维内跨题变化性、异常固定维度数和综合单一标签占比均已输出；
- 每人的强档率、同题同维同组强档率、强档差、强度一致率、同方向过度强调率及分维度结果均已输出；
- 输出的题号、Prompt、A URL 和 B URL 来自同一原始题记录；
- 人员质检 CSV 与 XLSX 关键数值一致；
- 人员过滤后每题权重之和为 1，各维四档等权质量之和等于题目数。
