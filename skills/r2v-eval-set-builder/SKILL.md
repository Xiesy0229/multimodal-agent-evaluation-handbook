# R2V 评测题集生成 Skill

版本：1.0.0。规则整理日期：2026-10-13。

## 目标与边界

交付可实际执行的“文本 + 参考图”评测输入，而不是只有题干的清单。输出包括题目、实际图片文件、标签、考察依据、来源和复核记录。

- 默认任务为150题、每题10秒；输入仅限文本与静态图片，不含视频、音频、mesh。
- 本包不预装图片、题库、第三方产品skill或账号，也不保证第三方平台可接收20张图。它提供规则、默认配置与本地检查工具。
- 用户最新确认的要求优先于默认配额。更改题量时同步调整交叉配额，不能悄悄丢弃难以完成的要求。
- 仅要求计划、skill或小样时，停留在该阶段。不得因读到本skill就自动生成全套、上传文件或运行收费模型。
- 默认只创建新交付物。回填前确认目标表格和工作表，不覆盖已有题目；访问、上传、下载均使用当前环境实际提供且获准的工具。

## 先读什么

1. 开始任何题库任务：读取 [默认配置](assets/default_config.json) 和 [分类及配额](references/taxonomy-and-quotas.md)。
2. 出题、改写、复核：读取 [生成与复核规则](references/generation-and-review.md)。
3. 寻找、下载或上传图片：读取 [素材与交付规则](references/assets-and-delivery.md)。
4. 组织数据、运行检查或导出表格：读取 [数据格式与检查](references/data-contract.md)。

若用户提供新的需求文档，先实际读取指定版本；记录未填写和无法访问的部分，不凭标题推断内容。不得擅自把建议、评论或其他版本当成已生效标签。

## 默认交付规格

| 项目 | 默认要求 |
|---|---|
| 总题数 / 时长 | 150题 / 每题10秒 |
| 语言 | 中文75题，英文75题；独立题目，不以翻译副本凑数 |
| 镜头 | 单镜头75题，多镜头75题；多镜头以2-3镜头为主 |
| 描述风格 | 用户口语60题、自然详述50题、结构化分镜34题、超长详述6题 |
| 超长题 | 6道中文正文，每道2000-3000个汉字，另记录非空白字符数；不能用重复文本凑数 |
| 1-10张参考图 | 对应题数为30、25、20、16、14、10、8、7、6、5，共141题 |
| 边界参考数量 | 11-18张各1题，20张1题，共9题；符合“8题左右”的边界规模 |
| 改写专项 | 6题实际完成有来源记录的skill或模板改写，计入150题而非额外加题 |
| 覆盖 | 9类主体、14类能力；数量、否定、概念组合各至少5题，安全合规至少3题 |
| 人物日常场景 | 默认至少20题，包含走路、办公、吃饭、递物、购物、家庭或社会互动 |
| 小样 | 先做12题，包含中英文、超长、书写、低中高图数、11-18张及20张边界题 |

“人物日常至少20题”和各能力最低覆盖数是本包的执行默认值，不是通用行业标准。用户有项目分布时以项目配置为准。

## 工作流程

### 1. 对齐需求

形成“需求 -> 题号 -> prompt证据 -> 图片 -> 观察标准”的覆盖表。未明确的输出比例、分辨率、模型参考数量上限、提示词长度上限列为待核实。

不要把“支持图像输入”推断为“支持全部参考数量”。默认不调用生成模型，不把未运行的模型能力写成验证结论。

### 2. 先确定素材

在整个GitHub公开范围检索，而不是限定某个组织。优先获取实际的输入参考图和配对指令；视频或图像的生成结果不能冒充原始输入图。

逐张检查图片与用途，建立稳定的编号、顺序、来源、文件和校验值。随后围绕素材出题，不先编出具体图片细节再声称已有对应素材。

### 3. 按考察点写题

每题一个主考察点、至多两个辅助考察点。为每个标签保留prompt中的证据，并定义可以观察到的成功和失败表现。

自然表达与专业表达混合，保持英文自然。用户口语风格不等于真实用户来源。中英题干可混排，但每题的主语言需要明确。

### 4. 审核10秒可执行性

为审核建立覆盖0-10秒的内部时间安排。它不必显示在最终用户风格prompt中。

检查主体动作、过程所需时间、镜头切换、台词和结尾观察时间。长prompt用于细化同一片段的约束，不增加超出10秒的大量事件。

书写题需看到笔尖与笔画形成，不能只检查最后的字是否正确。多图题不等于多主体、多动作或多镜头。

### 5. 小样与改写

先完成12道带实际图片的小样并运行检查。用户要求确认小样时，等待确认再扩展；用户已明确授权全程执行时，可自行完成小样复核后扩展。

改写6题时保留原文、实际使用的skill或模板、版本/来源和改写后文本。没有调用产品skill时不得写成“即梦/小灵雀官方skill改写”；可如实采用公开模板或已实际读取的自建skill。

### 6. 独立复核与补齐

让另一名复核者在不看作者自评结论的情况下检查原始题目和图片。具备子代理能力时可采用独立子代理；没有时如实记录单代理复核，不能伪称双人审查。

按需修改题目，再检查配额与重复。不能为了达成配额，给prompt未提出的能力硬贴标签。

### 7. 导出与按授权回填

输出本地题集、图片包、覆盖与复核报告。按用户要求将图片实际上传到指定工作表，保持原始顺序；上传完成后重新读取并核对。

缺少权限、合适工具或图像访问能力时，交付可审计的本地部分成果，明确阻塞项；不能把图片描述、搜索页或占位图当完成。

## 检查工具

ZIP版本带有仅依赖Python 3.9及以上标准库的检查器。命令在skill目录内运行，参数指向实际题集和素材根目录：

```bash
python3 scripts/validate_cases.py cases.jsonl --asset-root dataset --stage pilot
python3 scripts/validate_cases.py cases.jsonl --asset-root dataset --stage full --report checks.json
python3 scripts/validate_cases.py cases.jsonl --asset-root dataset --stage full --require-uploaded
python3 scripts/test_validate_cases.py
```

首次使用或修改配额后，先运行：

```bash
python3 scripts/validate_cases.py --check-config
```

此检查器不联网、不上传、不运行生成模型。通过只代表所检查的结构与数量一致，不证明图片匹配、授权有效、语义去重或动作可在10秒内完成。这些仍需具备图像理解能力的复核者检查。

## 收尾说明

明确区分：计划完成、小样完成、全套本地完成、回填上传完成、实际模型评测完成。未执行的阶段不能标成完成。

最终应报告实际题数、图数分布、中英及镜头比例、超长题数量、边界任务类型、未解决问题，以及本地检查和人工/代理复核各自覆盖的范围。
