# 分类及配额

本文件是共享包内的完整分类口径，不依赖访问内部文档。后续用户提供新的正式版本时，先对照差异，再更新配置与校验，不能把新版侧栏入口自动当成本次标准。

## 字段映射

| 展示字段 | 数据字段 | 口径 |
|---|---|---|
| 题号 / 题名 | id / title | 唯一编号与自然题名 |
| 题目类型 | task_type | R2V任务说明，例如“人物身份保持与转身” |
| 主体题材 / 主题 | subject_tags | 下表9类；首项作为主要题材，可附其他确有依据的题材 |
| 能力类别 | primary_capability / secondary_capabilities | 一个主考察点，至多两个辅助点 |
| 镜头数量 | shots | 实际镜头数；运镜不等于切镜头 |
| 描述类型 | style | 用户口语、自然详述、结构化分镜、超长详述 |
| 长度标签 | length_label | 极短、短、长；超长是另一个专项，不替换原长度分类 |
| 语义复杂度 | complexity | 简单、中等、困难 |
| 语言 | language | 中文zh或英文en |
| 题目来源 | source.type | arena、过往hardcase、用户prompt、业务、手写 |
| 参考图数量 | refs数组长度 | 实际输入图片文件数量，不是拼贴中的画面数量 |
| 补充标签 | supplemental_tags | 非正式类别，例如特效、构图、日常场景 |

## 主体题材

| ID | 标签 |
|---|---|
| human | 人物 |
| animal_creature | 动物/生物 |
| multi_subject | 多主体 |
| object | 物体：食物、工具、载具、植物等 |
| natural_landscape | 自然景观 |
| built_space | 人造空间/场景 |
| abstract | 无明确主体：抽象流体、线条、抽象艺术等 |
| anime_fantasy | 动漫卡通/非现实 |
| text_primary | 以文字为主：文字、字幕、标题，也包含以书写为核心的题 |

按题目的主要视觉内容判断，不能把所有出现文字的题都设为“以文字为主”，也不能把所有含参考图的题都设为“多主体”。

## 能力类别

| ID | 正式类别 | 判定依据 |
|---|---|---|
| multi_subject_action | 多主体/多动作指令 | 主体有各自明确动作，或明确发生交互 |
| expression_physiology | 情绪表情与生理动作真实度 | 对微表情、肢体语言或生理动作有明确要求 |
| physics_material | 物理规律与材质细节 | 关注碰撞、重力、流体、受力或材质表现的合理性 |
| temporal_motion | 时序动态与运动连续性 | 关注动作过程、速度变化、阶段衔接 |
| camera_control | 镜头参数与运镜 | 本配置按“有实际运镜才计入”的收紧口径；只写电影感或焦距不足 |
| lighting_style | 光影风格 | 明确规定光源、方向、氛围或视觉风格 |
| multi_shot_narrative | 多镜头叙事与剪辑连贯性 | 至少两镜头，且明确要求叙事、动作、主体或空间衔接 |
| commercial_design | 视觉设计与商业表达 | 广告、电商、品牌或产品信息表达有明确目标 |
| text_layout | 文字生成与动态图文排版 | 要求具体可读文字或明确书写过程 |
| spatial_composition | 空间组合 | 明确前后、内外、遮挡、层次或相对位置 |
| counting | 数量理解 | 要求确切数量，且数量在画面中可辨认 |
| negation | 否定生成 | 有可观察、可核查的否定要求 |
| concept_combination | 概念组合 | 明确组合通常不共存的概念 |
| safety_compliance | 安全与合规 | 明确测试适当的安全边界；不以露骨或伤害细节堆砌题库 |

不能只因“视频总有时间变化”而给每题贴temporal_motion，也不能把通用的“不要变形”一律作为否定专项。补充标签中的特效、美学或构图，不擅自替代上表正式类别。

## 长度与复杂度

- 极短 `tiny`：少于10词。
- 短 `short`：10至30词，含边界。
- 长 `long`：大于30词。
- 超长详述仍属于长标签，但style为`ultra_long`，默认中文正文2000-3000个汉字，字数不包含题号、表头、标签及参考图元数据。
- 中文“词”与“汉字”不是同一单位。全项目采用同一种中文分词方法和版本，记录word_count及word_count_method；不得用汉字数伪装词数。
- 检查器可核算汉字数、非空白字符数及英文词数，但不会验证中文分词器真的被运行，也不会验证主语言是否正确。
- 简单 `simple`：一个明确能力维度；中等 `medium`：两个；困难 `hard`：三个及以上。本配置每题最多三个能力标签。
- 长度不决定复杂度。2000字描述一个动作，不自动属于困难题。

## 配额之间的关系

语言、图数、镜头、风格是四个交叉配额，分别合计150，不相互叠加。6个改写题包含在150题内，6个超长题也包含在风格配额内。

12题小样只强制要求覆盖指定语言、专项和图数区间，不机械缩放150题配额。建议中英各6、单多镜头各6；风格可采用口语5、自然详述4、结构化2、超长1。该小样风格分配是建议值，检查器不把它当硬配额。

参考图档位覆盖1-18及20张；19张不是默认必测档。9道边界题需覆盖9种有实质差异的任务，不能只改数量：

1. 11张：同主体多视角融合。
2. 12张：商品局部细节保持。
3. 13张：人物与道具绑定。
4. 14张：服装或属性绑定。
5. 15张：场景空间组合。
6. 16张：风格与内容分离。
7. 17张：多镜头主体一致性。
8. 18张：指定参考选择。
9. 20张：综合多参考约束。

以上是排题建议，实际素材不足时可以交换类型与数量，但不得编造素材或减少数量档位。`boundary.type`应表达可辨识的任务差异，不能用9个不同ID包装同一种任务。

单镜头与多镜头各75题。多镜头主要2-3镜头，可安排少量4-5镜头；6-15镜头属于可选边界，不要求每种都出现。只有在10秒内确实合理的快速蒙太奇等场景才使用，不能让每个短镜头都完成复杂动作。

默认至少20个人物日常场景。只在`daily_human=true`且human题材确实成立时计数，避免人物题全部是高难度动作。

## 来源诚实性

`source.type`映射为：arena / 过往hardcase / 用户prompt / 业务 / 手写。

来自公开基准但经过原创改编的题可标“手写”，同时在origin_url和adaptation记录原始基准及改编方式；不要无依据标成arena。真实用户prompt必须有实际来源记录。仅仅写得口语化，来源仍可能是“手写”。
